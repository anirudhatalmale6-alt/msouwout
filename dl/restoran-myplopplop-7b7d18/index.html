  1. Sign up: myplopplop.com/merchant/register.html, category "🍽️ Restaurant / Food", storefront photo + ID → "🏪 Create My Store".
  2. Wait for HaitiBiznis verification. Meanwhile, add your menu.
  3. Products → "+ Add a product": photo, name, price, quantity, category → "Save".
  4. Settings: "Store is open", hours, then "I offer delivery" (delivery fee 0 = MsouWout price).
  5. Orders: prepare ONLY when it says "✅ Paid" → "Accept" → "Preparing" → "Ready — call the driver".
  6. Type the driver's pickup code → "Hand over to driver". The sale shows in Wallet.
