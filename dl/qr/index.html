How to check any code yourself

Hold your own phone camera up to it before you send it anywhere. If the phone does not offer to open the site, the code is a drawing. There is no half-working code — it either opens or it is decoration.

One limit worth knowing

The flyer files you sent are 1024 × 1536. That is small for print. I doubled them and the code itself is drawn fresh, so the code is sharp at any size — but the photographs and the writing around it can only ever be as sharp as the file the AI gave you.

For a poster or anything bigger than a hand flyer, ask for the artwork again at a larger size and I will put the code back on, or hand the shop the SVG above and let them place it themselves.

Do not stretch the code or crop the white edge.

The white border is part of it. Scale evenly, keep it square, leave the white. Keep it above 1.5 cm on paper and it is comfortable to scan.
